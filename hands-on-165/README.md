# Hands-on 165: Basic Function Call

## Purpose
Practice calling a named function and printing its returned value.

## What This Program Shows
- `LearningGo(x string) string` returns the same string it receives.
- `main()` stores the result and prints it.
- The example keeps the logic minimal so the function call flow is easy to see.

## Run
```bash
go run .
```

## Expected Behavior
The program prints `Go is interesting`.

## Key Takeaway
Small examples are useful for reinforcing how arguments move into functions and values come back out.
