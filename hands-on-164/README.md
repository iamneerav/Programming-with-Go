# Hands-on 164: Anonymous Functions

## Purpose
Demonstrate immediately invoked anonymous functions in Go.

## What This Program Shows
- One anonymous function adds two integers and returns the result immediately.
- Another anonymous function prints numbers from `0` to `9`.
- `main()` shows both patterns in one program.

## Run
```bash
go run .
```

## Expected Behavior
The program prints `5`, a separator, a label line, and then the numbers `0` through `9`.

## Key Takeaway
Anonymous functions are useful when behavior is needed only once and does not need a named declaration.
