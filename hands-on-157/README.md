# Hands-on 157: Struct Methods

## Purpose
Show how to define a struct type and give it behavior through a method.

## What This Program Shows
- `person` stores a first name and age.
- `speak()` is a method with a `person` receiver.
- `main()` creates a `person` value and calls its method.

## Run
```bash
go run .
```

## Expected Behavior
The program prints a sentence introducing the person and their age.

## Key Takeaway
Methods let structs carry both data and related behavior.
